# Prototype Expense Tracker
โค้ดนี้เป็นการเขียนแอปที่มีฟีเจอร์หลักเป็นการคำนวน รายรับ-รายจ่าย และเงินได้สุทธิ ซึ่งเป็น prototype เบื้องต้น

# โครงสร้างไฟล์
- ตำแหน่ง lib/main.dart

# ฟีเจอร์เด่น (Key Features)
- คำนวณรายรับ, รายจ่าย และยอดเงินคงเหลือ อัตโนมัติ
- แสดงประวัติรายการ พร้อมแยกสีและไอคอนตามประเภท (รายรับ-เขียว / รายจ่าย-แดง)
- ระบบตรวจสอบการกรอกข้อมูลและเลือกวันที่ย้อนหลังได้

# วิธีติดตั้ง
1. git Clone หรือ Download โฟลเดอร์นี้ไปที่เครื่องของคุณ
2. เปิดโฟลเดอร์ด้วย VS Code หรือ Android Studio
3. เปิด Terminal แล้วรันคำสั่ง: 
    flutter pub get
    flutter run
4. แก้ไขไฟล์ที่ lib/main.dart
